# Hegira v0.7.0

This is a pre-tag source candidate. No v0.7.0 tag or GitHub Release has been
published.

The current source checkout aligns framework, official-module, tooling,
component-package, and canonical application identities to v0.7.0. Default
and minimal application lockfiles retain the normal release-tag Git source
and resolve it to the reviewed #350 candidate revision.

The immutable v0.6.0 application baselines remain unchanged. The package now
declares a data-only upgrade edge for default, minimal, and Identity-added
SQLite/PostgreSQL applications. The public CLI exposes read-only `upgrade status`
and reviewable `upgrade --dry-run` with authenticated readiness, plus `upgrade`
for atomic application of the same typed plan with deterministic receipts and
explicit application-owner next steps. Committed JSON schemas, reviewed
human/JSON snapshots, and typed diagnostics/process-outcome tests stabilize
the upgrade automation contract. A shared public-process matrix verifies readiness,
preview, apply, repeat rejection, inspection, doctor compatibility, and protected
resource capability gating across all six supported released compositions. The
layered-template gate compiles each customized public-upgrade result for native
and WASM hydration in separate local-source validation staging. Final
release notes and the release date are verified during release preparation.
