# Hegira v0.7.0

This is a pre-tag source candidate. No v0.7.0 tag or GitHub Release has been
published.

The current source checkout aligns framework, official-module, tooling,
component-package, and canonical application identities to v0.7.0. Default
and minimal application lockfiles retain the normal release-tag Git source
and resolve it to the reviewed #350 candidate revision.

The immutable v0.6.0 application baselines remain unchanged. The package now
declares a data-only upgrade edge for default, minimal, and Identity-added
SQLite/PostgreSQL applications. The public CLI does not yet expose upgrades. Final
release notes and the release date are verified during release preparation.
